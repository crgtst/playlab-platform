# openapi-java-client

PlayLab Shop API

- API version: 1.0.0

- Generator version: 7.19.0

REST API for PlayLab Shop, a practice e-commerce site built to be tested with Playwright.

* All money values are integer cents in EUR.
* Every error uses the same shape: `{ \"error\": { \"code\", \"message\", \"details\", \"correlationId\" } }`.
* Every response has an `X-Correlation-Id` header. Send your own (1 to 64 of `A-Z a-z 0-9 - _`) to have it echoed;
  otherwise, or if it is invalid, the API generates a UUID. Errors repeat it as `error.correlationId`.
  With test hooks on, `GET /test/logs?correlationId=` returns that request's redacted log line.
* Authenticate with `Authorization: Bearer <accessToken>` or the `session` cookie set by `/auth/login`.
* Access tokens expire after 15 minutes; use `/auth/refresh` to get a new one.
* Deleting an account (`DELETE /users/me`) ends all its sessions: its access tokens then return 401 `TOKEN_REVOKED`.
* Rate limit: 100 requests a minute per user (or per IP for guests). Over the limit returns 429 with `Retry-After`.
  A guest's IP comes from `X-Forwarded-For` only when the web proxy sends it.
* Test hooks under `/test/_*` exist only when the API runs with `TEST_HOOKS=true`.
* Test sessions: `POST /test/sessions` returns an id. Requests that send it as `X-Test-Session` (or the
  `test_session` cookie) get that session's own defects, clock, latency and chaos rules and rate-limit counters;
  hook calls with it change only that session. Requests with no session use the global state.
* Live order status: WebSocket at `ws://<host>/ws/orders` (not describable in OpenAPI).
  Authenticate with the `session` cookie or `?token=<accessToken>`; without either the upgrade gets 401.
  Messages: `{\"type\":\"hello\",\"userId\",\"role\"}` on connect, then
  `{\"type\":\"order.status\",\"orderId\",\"number\",\"status\",\"from\",\"at\"}` for your orders (admin and support: every order).
  Send `{\"type\":\"ping\"}` to get `{\"type\":\"pong\"}`.
* Live stock: Server-Sent Events at `GET /api/v1/stock/stream`.

## Installation

To install the API client library to your local Maven repository, simply execute:

```shell
mvn clean install
```

To deploy it to a remote Maven repository instead, configure the settings of the repository and execute:

```shell
mvn clean deploy
```

Refer to the [OSSRH Guide](http://central.sonatype.org/pages/ossrh-guide.html) for more information.

### Maven users

Add this dependency to your project's POM:

```xml
<dependency>
  <groupId>org.openapitools</groupId>
  <artifactId>openapi-java-client</artifactId>
  <version>1.0.0</version>
  <scope>compile</scope>
</dependency>
```

### Gradle users

Add this dependency to your project's build file:

```groovy
compile "org.openapitools:openapi-java-client:1.0.0"
```

### Others

At first generate the JAR by executing:

```shell
mvn clean package
```

Then manually install the following JARs:

- `target/openapi-java-client-1.0.0.jar`
- `target/lib/*.jar`
